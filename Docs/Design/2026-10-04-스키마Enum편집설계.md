# 웹에서 스키마 · enum 편집 설계 (1판)

> 결론 : 웹이 **바뀐 스키마 전체 + 무엇을 바꿨나(ops)** 를 보내면 서버가 데이터 행까지 따라 고친다.
> 먼저 `plan` 으로 영향만 보고, `PUT` 으로 쓴다. 검증에 하나라도 걸리면 한 글자도 안 쓴다.
> enum 은 C# 숫자를 고정할 수 있게 둘째 꼴 `{"common":0,"rare":1}` 을 받는다. 백엔드는 2026-10-04, 웹 화면(「스키마」·「Enum」 탭)은 2026-10-05 에 붙었다.

## 1. 정한 것 (사용자 승인 2026-10-04)

| # | 무엇 | 결정 |
| --- | --- | --- |
| 1 | 열 이름 바꾸기 | 데이터 행도 따라 고친다. 지시(ops)로 받는다 — 「지우기+더하기」로 짐작하지 않는다 |
| 2 | 쓰는 행이 있는 enum 값 지우기 | 대체 값 `replaceWith` 필수. 쓰는 행이 0 이면 그냥 지운다 |
| 3 | C# 숫자 고정 | enum 둘째 꼴 `{"common":0,"rare":1,"epic":5}`. 옛 배열 꼴은 차례 번호(0,1,2…). 숫자 중복 금지 · 0 이상 정수. 값을 더할 때 최댓값+1(웹 몫), 지운 숫자는 재사용 안 함 |
| 4 | 숫자와 `schemaHash` | 해시에 안 넣는다. 구운 파일에는 이름 문자열만 들어간다. 옛 스키마의 해시는 그대로다 |
| 5 | 스키마 파일 꼴 | 서버 정규형 `schema.Format`. `datatool fmt` 가 schema.json 도 정리한다 |
| 6 | enum 차례 | enum **이름**은 가나다 차례, enum **값**은 적힌 차례 그대로 |
| 7 | 백업 | 백업 폴더 없음. git 아래가 아니거나 바뀔 파일에 커밋 안 한 변경이 있으면 plan 에 경고(막지 않음) |
| 8 | 형 바꾸기 | 값을 자동으로 안 바꾼다. 안 맞으면 V3 로 막힌다 |
| 9 | 웹 「C# 만들기」 | `POST /api/gen`. 쓸 자리는 `.datatool.json` 의 `gen` 칸만. CLI `gen` 과 같은 판정(V10 은 오류) |
| 10 | CLI | 새 명령 없음 |
| 11 | 1판 범위 | enum 값 추가·이름 바꾸기·지우기·차례 바꾸기, enum 추가·이름 바꾸기, 열 추가·이름 바꾸기·지우기·차례 옮기기, 숫자 고정, gen API |

## 2. 저장 꼴 (`schema.Format`)

```json
{
  "version": 1,
  "namespace": "MyGame.Data",
  "enums": {
    "Element": ["fire", "ice"],
    "Grade": {"common": 0, "epic": 5}
  },
  "tables": [
    { "name": "item", "columns": [
      { "name": "id", "type": "string" },
      { "name": "grade", "type": "enum", "enum": "Grade", "default": "common" }
    ] }
  ]
}
```

- 열 한 줄에 하나. 칸 차례는 `name type enum ref kind min max default loc desc` 로 고정, 정렬용 공백 없음.
- enum 은 숫자가 `0,1,2…` 차례 그대로면 **배열 꼴**, 아니면 **객체 꼴**로 적는다. 같은 뜻이면 같은 글자다.
- `enums` 가 비면 칸을 안 적는다. 줄끝은 LF, 파일 끝 개행 하나.

## 3. API

모두 `X-Datatool-Token` 과 127.0.0.1 Host 가 필요하다 (`guard`). 본문 상한 32MB.

| 길 | 하는 일 | 쓰나 |
| --- | --- | --- |
| `GET /api/schema` | 옛 응답 + `rev` (schema.json 디스크 바이트의 sha256, 64자) + `enumNumbers` (`{Grade:[0,1,5]}`, `enums` 와 같은 차례) + `source` (파일 꼴 그대로의 JSON 객체 — 편집 화면은 이것을 고쳐 `schema` 로 돌려보낸다) | 안 씀 |
| `POST /api/schema/plan` | 본문을 그대로 돌려 보고 영향·검증·경고를 알린다 | 안 씀 |
| `PUT /api/schema` | 같은 본문 + `If-Match: <rev>`. 통과하면 표들과 schema.json 을 쓴다 | 씀 |
| `POST /api/gen` | 디스크의 스키마·데이터를 validate 하고 C# 을 `gen` 칸 폴더에 쓴다 | 씀 |

### 3-1. 본문 (plan · PUT 같음)

```json
{
  "schema": { "version": 1, "namespace": "MyGame.Data", "enums": {}, "tables": [] },
  "ops": [
    {"op": "renameColumn", "table": "item", "from": "atk", "to": "attack"},
    {"op": "dropColumn", "table": "item", "column": "usable"},
    {"op": "renameEnumValue", "enum": "Grade", "from": "rare", "to": "uncommon"},
    {"op": "dropEnumValue", "enum": "Grade", "value": "epic", "replaceWith": "uncommon"},
    {"op": "renameEnum", "from": "Element", "to": "Attr"}
  ]
}
```

- `schema` 는 schema.json 에 들어갈 **전체**다. `ops` 는 **차례대로** 적용한다 — 앞 op 뒤의 이름으로 다음 op 를 쓴다.
- ops 는 **저장된 스키마에 있던 것**에만 쓴다. 아직 저장 안 한 새 열·새 값은 이름을 바꿔도 op 를 안 낸다.
- 옛 열이 새 스키마에서 사라졌는데 `dropColumn` 이 없으면 막는다. enum 값도 같다 (`dropEnumValue`).
- 열 추가·차례 옮기기, enum 값 추가·차례 바꾸기, enum 추가는 op 가 없다 — 스키마만 바꾸면 된다.

### 3-2. plan 응답 (200 · 걸려도 200, `ok` 로 가른다)

```json
{
  "ok": true, "rev": "<지금 디스크 rev>",
  "files": [
    {"file": "item.json", "rowsChanged": 3, "valuesLost": 1},
    {"file": "schema.json", "rowsChanged": 0, "valuesLost": 0}
  ],
  "problems": [], "warnings": [],
  "notes": ["열 item.atk 기본값이 바뀐다 — 값을 안 적은 행 4개가 따라 바뀐다"]
}
```

- `problems` · `warnings` 는 `validate.Problem` 꼴(`file line table row column rule message`).
  스키마·ops 오류는 `rule` 이 `schema` · `op` · `gen` 이다.
- `notes` 는 사람이 읽을 경고 글이다 (git 상태 · C# 숫자 바뀜 · 기본값 바뀜).
- 본문이 깨졌으면(JSON·ops 꼴·모르는 칸) 400, Content-Type 이 JSON 이 아니면 415, 32MB 를 넘으면 413 — 다 `{ok:false, error}`.
- `files` 의 `file` 은 데이터 폴더 기준 이름이다. 바뀌는 것이 없으면 빈 배열이다.

### 3-3. PUT 응답

| 경우 | 코드 | 본문 |
| --- | --- | --- |
| 통과·씀 | 200 | `{ok:true, rev:<새 rev>, written:[…], warnings, notes}` |
| `If-Match` 없음 | 428 | `{ok:false, error}` |
| rev 다름 | 409 | `{ok:false, error, rev:<디스크 rev>}` — 아무것도 안 씀 |
| 검증에 걸림 | 400 | plan 과 같은 꼴 + `ok:false` — 아무것도 안 씀 |
| 쓰다 실패 | 500 | `{ok:false, error, written:[…], notWritten:[…]}` |

### 3-4. gen 응답

200 `{ok:true, dir, written:[…], stale:[…], warnings}`. 설정에 `gen` 칸이 없으면 400, 검증에 걸리면 400 + `problems`.

## 4. 검증·쓰기 차례 (PUT)

1. `s.mu` 를 잡는다. 디스크 schema.json 을 읽어 rev 를 견준다 — 다르면 409.
2. 옛 스키마·표 전부를 읽는다 (`loadAll`).
3. ops 를 옛 스키마 위에서 차례로 흉내 내 이름 지도를 만든다 (`internal/migrate`). 없는 것을 가리키면 `op` 문제.
4. 새 스키마 본문의 `default` 중 **옛 기본값 그대로인 것**만 enum 값 지도로 고친다. 그다음 `schema.Parse`.
5. 표마다 행 키를 옮기고·빼고, `enum`·`list<enum>` 값을 바꾼다. 옛 열·값이 op 없이 사라졌으면 문제.
6. `validate`(V10 은 경고 — 표 PUT 과 같다) + `gen.Generate` 의 이름 충돌 검사.
7. 하나라도 걸리면 400, 한 글자도 안 쓴다.
8. 바뀌는 파일 전부를 **먼저 tmp 로 다 쓴다.** 그다음 rename 을 잇는다 — 표 먼저, schema.json 마지막.
   tmp 단계에서 실패면 tmp 를 지우고 아무것도 안 바뀐다. rename 중 실패면 500 + 어디까지 썼나.

> `table.Format` 은 스키마에 없는 열을 조용히 버린다. 그래서 5의 「op 없이 사라진 열」 검사와 6의 validate 를 지난 뒤에만 쓴다.

## 5. 웹 화면이 할 일 (2026-10-05 붙음 · `ui/schema.js`)

- 「스키마」 탭(표마다 열 목록 : 더하기·이름 바꾸기·지우기·위아래)과 「Enum」 탭(값 더하기·이름 바꾸기·지우기·차례, enum 더하기·이름 바꾸기).
- 편집하는 동안 ops 를 차례대로 쌓는다. 저장 안 한 새 것의 편집은 op 를 안 낸다.
- 값을 더할 때 숫자는 지금 최댓값+1. 지우거나 차례를 바꿀 때 남은 값의 숫자는 그대로 보낸다 (객체 꼴).
- 저장 전에 늘 `plan` 을 불러 미리보기 창에 `files` · `problems` · `notes` 를 보여 준다. 확인을 눌러야 `PUT`.
- 쓰는 행이 있는 값을 지울 때 대체 값을 고르게 한다.
- **저장 안 한 행 편집이 있으면 스키마 편집을 막는다** (표 PUT 과 스키마 PUT 이 서로 덮지 않게).
- 409 를 받으면 다시 읽으라고 알린다.
- API 가 돌려준 글자는 전부 `textContent` 로 넣는다 — 값 속 태그가 토큰 쥔 페이지에서 돌 수 있다.
- 「C# 만들기」 단추 → `POST /api/gen`, `written` · `stale` 을 보여 준다.

붙이면서 더 정한 것은 7장 표 아래쪽(「웹 :」 줄)에 있다. U6 K1~K6 · X2 가 지킨다.

## 6. 보안 점검 (새 쓰기 길 셋)

| 길 | 점검 |
| --- | --- |
| schema.json | 자리는 `s.root`(뜰 때 `EvalSymlinks`) + 붙박이 이름. 브라우저에서 경로를 안 받는다 |
| 여러 표 | 표 이름은 새 스키마의 이름(`^[a-z][a-z0-9_]*$`)이고, 쓰기 전 `tablePath` 로 `validTableName` + `inside()` 를 다시 지난다. 1판은 표 집합이 바뀌면 막는다 |
| gen 폴더 | `.datatool.json` 의 `gen` 칸만. serve 가 뜰 때 한 번 절대경로로 쥐고(`EvalSymlinks`), 파일 이름은 `gen.Write` 의 `checkName` 이 막는다 |
| 문지기 | 새 길 셋(`/api/schema` PUT · `/api/schema/plan` · `/api/gen`) 다 같은 `mux` 를 지나 `guard`(Host·토큰·32MB)가 걸린다. 시험 `TestSchemaBodyChecks` 가 토큰 없는 plan 401 을 본다 |
| 원자 쓰기 | tmp 를 다 쓴 뒤 rename. 옛 파일을 먼저 지우지 않는다. 지우는 것은 제 tmp 뿐이다 |
| 우회 | `--force` 같은 문이 없다. 검증에 걸리면 400 이고 안 쓴다 |
| 오류 글 | 사용자 글자는 `%q` 로 감싼다. 응답은 JSON 이고 HTML 로 꾸미지 않는다 |
| git 확인 | `exec.Command("git", "-C", root, …)` — 셸 없이, 인자는 서버가 만든 파일 이름뿐, 5초 제한 |

## 7. 구현하며 정한 것

| 무엇 | 정한 것 | 까닭 |
| --- | --- | --- |
| 숫자 담는 자리 | `File.Enums` 는 그대로 두고 `File.EnumNumbers` 를 곁에 둔다. 없으면 차례 번호 | 값 목록을 쓰는 옛 코드를 안 흔든다 |
| 배열 꼴 / 객체 꼴 | 숫자가 0,1,2… 면 배열 꼴로 적는다 | 뜻이 같으면 같은 글자 (fmt 왕복) |
| 숫자 상한 | 0 ~ 2147483647 | C# enum 바탕형이 int 다 |
| ops 의 이름 | 차례대로 적용 — 앞 op 뒤의 이름을 쓴다 | 웹이 사람 손 차례대로 쌓기 쉽다 |
| 사라진 열·값 | op 없이 사라지면 막는다 | 「짐작하지 않는다」를 서버가 지킨다 · Format 이 값을 버리는 길을 닫는다 |
| default 고치기 | 새 default 가 옛 default 와 같을 때만 값 지도로 고친다 | 웹이 이미 고친 것은 안 건드린다 (값 맞바꾸기도 맞게 나온다) |
| 지운 값이 default | `replaceWith` 가 없으면 막는다 | 쓰는 행과 같은 취급 |
| 값 매핑 기준 | 옛 열이 가리키던 enum 의 지도로 바꾼다 | 형 바꾸기는 V3·V5 에 맡긴다 (결정 8) |
| C# 숫자 바뀜 | 옛·새에 다 있는 값의 숫자가 바뀌면 notes 경고 | 게임이 int 로 저장한 값이 어긋난다 |
| 기본값 바뀜 | 값을 안 적은 행 수와 함께 notes 경고. 값은 안 박는다 | 기본값의 뜻(빈 칸 값)을 지킨다 |
| `If-Match` 없음 | 428 | 덮어쓰기 확인 없이 쓰지 않는다 |
| 표 추가·지우기 | 새 스키마의 표 집합이 옛것과 다르면 막는다 | 2판 몫 · 파일 집합 검사(V8)와 엇갈린다 |
| 여러 파일 쓰기 | `table.WriteAll` (tmp 전부 → rename 차례) | 쓰기 규칙은 table 묶음 하나가 안다 |
| rev 의 바탕 | 디스크 바이트 그대로(BOM·CRLF 포함) | 손으로 고친 것도 「바뀜」으로 잡는다 |
| schema.json 줄끝·BOM | 정규형(LF, BOM 없음)으로 다시 쓴다. 되살리지 않는다 | 이 툴의 원본이고 `fmt` 와 같은 규칙이다 (남의 설정 파일이 아니다) |
| 쓰는 자리가 링크 | 이미 있는 표·스키마 자리가 보통 파일이 아니면 안 쓴다 | 경로 감옥의 「보통 파일 확인」 |
| plan 의 git 확인 | plan 에서만 돈다. PUT 은 안 돈다 | 미리보기에서 한 번 보면 된다 · PUT 을 느리게 안 한다 |
| gen 폴더 정규화 | 있으면 링크까지 푼 경로, 없으면 절대경로만 (gen.Write 가 만든다) | 처음 gen 은 폴더가 없다 |
| gen 흐름 | `gen.Build(sch, dir)` = Generate + Write, CLI·serve 가 같이 쓴다 | 같은 흐름 |
| 웹 : 보내는 enum 꼴 | 늘 객체 꼴 `{"이름":숫자}` 로 보낸다. 0,1,2… 면 서버가 배열 꼴로 적는다 | 숫자를 웹이 쥐고 있어야 지우기·차례 바꾸기에 안 밀린다 |
| 웹 : enum 이름 바꾸기 | 그 enum 을 쓰는 열의 `enum` 칸도 웹이 같이 고친다 | 서버는 새 스키마를 그대로 받는다 — 열이 옛 이름을 가리키면 검증에 걸린다 |
| 웹 : 쓰는 값인지 | 웹은 값마다 쓰는 행 수를 모른다. 지우기 창에서 대체 값을 고를 수 있게만 하고, 막힘은 plan 의 `problems` 로 보인다 | API 에 값별 쓰임 수가 없다 (넘긴 것) |
| 웹 : 미리보기 목록 | 목록마다 30건까지 보이고 「그 밖에 N건」 | 쓰는 값을 지우면 행마다 문제 한 줄이라 수백 줄이 된다 · 창 단추가 화면 밖으로 밀렸다 |
| 웹 : 기본값 칸 | JSON 으로 읽히면 그 값, 아니면 글자 | `0`·`true`·`[]` 와 글자를 한 칸에서 쓴다 |
| 웹 : 서로 막기 | 저장 안 한 행이 있으면 스키마·Enum 탭 입력을 통째로 끈다. 스키마 편집이 남아 있으면 표 편집·행 추가·저장을 끈다. 막은 까닭은 탭 위 한 줄 | 표 PUT 과 스키마 PUT 이 서로 덮지 않게 (5장) |
| 웹 : Ctrl+S | 데이터 탭은 표 저장, 스키마·Enum 탭은 미리보기 창 열기 | 저장은 늘 미리보기를 거친다 |
| 웹 : 저장 뒤 | 스키마를 다시 읽고, 보던 표를 다시 연다 | 이름이 바뀐 열이 표에 바로 보인다 (U6 K1) |
