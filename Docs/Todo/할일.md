## 1단계에서 정해 둔 것 (뒤 단계가 그대로 쓴다)

- 종료 코드 상수는 `cmd/datatool/main.go` 에 있다 — 0 성공 · 1 사용법 · 2 데이터 · 3 스키마 · 4 읽기 · 5 쓰기.
- 스키마 오류는 `*schema.Errors` 다. 이것이면 종료 3, 그 밖의 오류면 종료 4 로 가른다.
- `schemaHash` 는 `(*schema.File).Hash()` — **파일 바이트가 아니라 정규형**을 해시한다.
  들여쓰기나 칸 차례를 바꿨다고 게임이 소리치면 안 되기 때문이다. `desc` 는 해시에서 뺀다.
- 아직 없는 명령은 `main.go` 의 `notYet` 표에 있다. 만들 때 그 줄을 지우고 `switch` 에 넣는다.

## 소단계 10 에서 정해 둔 것

- **`export`·`gen` 은 `loadAndValidate` 하나로 「먼저 validate」한다** (설계 5장). 검사하는 자리가
  둘로 갈리면 한쪽만 고치는 일이 생긴다. 걸리면 한 바이트도 안 쓴다.
- **데이터 폴더 찾기는 `cmd/datatool/config.go` 한 곳**이다. `--data` 가 없으면 지금 폴더에서 위로
  올라가며 `.datatool.json` 을 찾고, 한 칸마다 그 폴더와 그 아래 `GameData/` 둘을 본다.
  못 찾으면 폴더를 지어내지 않고 종료 1 이다.
- **내보낼 자리 차례는 「명령 옵션 > `.datatool.json` > 붙박이 기본값」** 하나뿐이다.
  설정의 절대 경로·다른 드라이브는 막지 않되 무엇을 쓸지 stderr 에 한 줄 찍는다.
- `.datatool.json` 에 모르는 칸이 있으면 조용히 넘기지 않고 종료 4 다. **BOM 은 벗겨서 읽는다** —
  PowerShell 의 `Set-Content -Encoding utf8` 이 BOM 을 붙여서 실측 중에 한 번 걸렸다.

## 2차로 미룬 것

설계 10장의 자리다. **1차에서는 대응 코드를 미리 안 짰다** — 안 쓰는 코드는 썩는다.

| 무엇 | 비워 둔 자리 |
| --- | --- |
| 암호화 | 머리 플래그 bit0 + 예약 6바이트 · `export --key-file <경로>` |
| 압축 | 같은 플래그 bit1. 차례는 압축 → 암호화 |
| 엑셀 가져오기 | `import --xlsx <파일> --table <이름>` (늘 `fmt` 를 거쳐 쓴다) |
| 다국어 | `"loc": true` 가 붙은 열만 뽑는 `loc-export` |
| 표 쪼개 굽기 | `export --split` (Addressables 로 옮길 때) |
| `GameDataIds.cs` | 표마다 id 상수 (메인 판단 4번으로 1차에서 뺐다) |

## Unity · 웹 확인 U1~U6

Go 시험으로는 못 보는 것들이다. 처음엔 사람 몫이었다.

**2026-10-03 사람 없이 자동 판정으로 바꿨고, 전부 통과했다.** U1~U5·U4b 는 Unity 배치모드(`Unity/Verify/verify.ps1`),
U6 은 크롬 headless CDP(`Test/u6/run.ps1`, 시나리오 24개)가 판정한다. 설계 `../Design/2026-10-03-Unity검증과웹개선설계.md`.

| # | 무엇 | 아는 것 | 판정 |
| --- | --- | --- | --- |
| U1 | 생성 `.cs` 를 넣고 Unity 를 연다 | 컴파일 오류 0 · MessagePack 소스 제너레이터가 도는가 | **통과** (verify EditMode) |
| U2 | `gamedata.bytes` 를 넣고 `Load` 를 부른다 | **Go 가 구운 것을 C# 이 읽는가** ← 직접 쓴 MessagePack 의 판가름 | **통과** |
| U3 | 값 대조 | 한글이 안 깨지나 · float 이 안 어긋나나 · enum 이 맞나 | **통과** |
| U4 | 스키마만 고치고 안 구운 채 실행 | `schemaHash` 가 달라 예외가 나는가 | **통과** |
| U4b | 열 타입이 바뀐 파일(`Unity/Verify/Fixtures/u4b/`) | 표 읽기 예외가 `GameDataException` 으로 싸이는가 | **통과** |
| U5 | IL2CPP 빌드 (Win64 플레이어 실행까지) | 리플렉션 없이 도는가 | **통과** |
| U6 | `serve` 로 2,000행 편집 후 저장 | **git diff 가 고친 줄만 나오는가** (설계 7장 23개 + S10) | **24/24 통과** (10-03 S10 추가 뒤) |

다시 돌리는 명령 (DataTool 폴더에서, 둘 다 종료 0 통과 · 1 판정 실패 · 2 환경 문제) :

```powershell
.\Unity\Verify\verify.ps1 -Project <빈 시험 Unity 프로젝트> -DataTool .\bin\datatool.exe   # U1~U5 · U4b (약 1분)
.\Test\u6\run.ps1 -DataTool .\bin\datatool.exe                                            # U6 (약 40초)
```

verify 는 **빈 시험 프로젝트나 사본에서만** 돌린다 (Generated · StreamingAssets · Plugins/MessagePack 을 덮어쓴다).
돌리기 전에 그 프로젝트의 `Temp/UnityLockfile` 이 없는지(에디터가 안 열려 있는지) 본다.

## 2026-09-18 코드 리뷰 후속

전체 툴 코드 리뷰 판에서 이 툴은 발견 10건 중 9건을 고쳤다 (시험 140 통과). 아래가 남은 것이다.

### 설계를 바꿔야 풀린다 — 별도 판 (사용자 결정 2026-09-18)

**D9 — 스칼라 값 변환기가 세 벌이다.** `internal/schema/check.go` · `internal/validate/value.go` ·
`internal/bake/bake.go` 의 `convertScalar` 가 각자 「이 글자를 이 타입으로 받을 수 있나」를 판정한다.
셋이 조금씩 달라서 **검사는 통과하는데 굽다가 터지는** 일이 났다(D3·D4).
이번 판에서는 세 곳을 각각 맞추는 임시 고침만 했다 — 중복은 그대로 남아 있다.

같이 볼 것 : 스키마 기본값 `"default": 12.0` 은 **여전히 통과하고 bake 에서 터진다.**
`validate` 의 `intForm` 과 같은 한 줄이면 막힌다.

### 이번 판에서 새로 드러난 것

- **`bin/datatool.exe` 를 다시 안 구웠다.** 배포하기 전에 `build.ps1` 을 한 번 돌려야 한다.
- **D8(UI 의 list 칸 왕복)을 브라우저에서 안 봤다.** Tabulator 위에서 쉼표 든 원소가
  제대로 도는지는 사람이 열어 봐야 안다.
- `UnknownColumns` 도 표당 100건에서 자른다. 열이 아주 많이 틀린 파일이면 뒤쪽이 안 보인다.

## 2026-09-21 실행 파일 낡음 대책

`build.ps1` 이 빌드한 커밋을 같이 박고, `datatool version` 이 「판 · 커밋 · 빌드 시각」을 찍는다.
README 빌드 절에 「소스를 받은 뒤에는 다시 빌드」 한 줄을 넣었다. `bin` 은 git 에 안 올라가서
서브모듈만 갱신하면 옛 실행 파일이 남기 때문이다.
