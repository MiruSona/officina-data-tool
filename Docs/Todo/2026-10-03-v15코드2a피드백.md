## 막힌 것

- **enum 값 꼴 규칙이 README 에 없다.** `"DecorLayer": ["Back", "Front"]` 로 적었더니 `validate` 가 종료 3 과
  「값 꼴이 틀렸다 (^[a-z][a-z0-9_]*$)」 를 냈다. README 「스키마 타입」 표의 `enum` 줄에 「값은 소문자 snake」 한 마디가 있으면 한 번에 맞힌다.

- 소문자 값(`back`/`front`)을 넣으니 `gen` 이 C# enum 은 `Back`/`Front` 로, 이름 문자열 상수와 `Layer` 속성까지 만들어 줘 그대로 썼다.
- `fmt --check` → `validate` → `export` → `gen` 네 번에 끝났다. 새 표가 `GameDataTables` 에 붙고, 나머지 생성 파일은 schemaHash 한 줄만 바뀌어 diff 가 읽기 쉬웠다.
