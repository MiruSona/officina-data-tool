# 웹 serve 현황과 U6 조사

> 2026-10-03 · 조사. `datatool serve`(웹 표 UI)가 지금 무엇을 하는지, U6 을 사람 대신 코드로 판정할 수 있는지,
> 사용자가 써 보기 전에 고쳐 둘 것이 무엇인지 본다.

## 0. 결론 먼저

- **U6 은 설치 없이 코드로 판정된다.** 이 기계의 Node 22 에 WebSocket 이 들어 있어서, 크롬 headless 를
  `--remote-debugging-port` 로 띄우고 CDP 를 직접 부르면 된다. Playwright 같은 새 패키지가 필요 없다.
  실제로 2,000행 표에서 더블클릭 → 타자 → Enter → 저장 버튼 → `git diff --numstat` 까지 돌려 봤다.
- **합격선 ④(git diff 에 고친 줄만)는 「보통 경우」에 통과한다.** 세 칸 고침 → `3 3`, 정렬 뒤 한 칸 → `1 1`,
  안 고치고 저장 → 0, 고치고 Ctrl+Z → 0.
- **하지만 조용히 데이터가 바뀌는 길이 셋 있다.** 사용자가 쓰기 전에 고치는 것이 좋다.
  1. **엑셀에서 복사해 붙이면 바로 아래 행이 지워진다.** 엑셀은 끝에 줄바꿈을 붙이는데, 그 빈 줄이 다음 행의 칸을 빈 값으로 덮는다.
     기본값이 있는 열이면 검증도 못 잡고 기본값으로 저장된다. 줄끝 `\r` 은 문자열 칸에 그대로 남는다.
  2. **편집 칸이 열린 채 Ctrl+S 를 누르면 마지막 입력이 빠진 채 「저장했다」가 뜬다.**
  3. **숫자 철자가 `300.0` · `1.25e1` 꼴이면 안 고친 줄도 diff 에 나온다.** `fmt` 는 이 꼴을 「규칙대로다」로 두는데,
     브라우저가 숫자를 읽었다 다시 쓰면서 `300` · `12.5` 로 바꾼다. 설계 9장이 막으려던 「UI 와 fmt 의 diff 가 갈림」이 숫자에서 남아 있다.
- 그 밖에 **저장 실패를 알리지 않는 경우**(서버가 꺼졌을 때 아무 표시 없음), 검색·거르기 없음, 여러 행 지우기 없음 같은
  쓰기 편함 문제가 있다. 4장 표에 우선순위와 크기를 붙였다.

## 1. 지금 serve 가 하는 것

### 1-1. API

| API | 하는 일 | 파일을 쓰나 |
| --- | --- | --- |
| `GET /api/schema` | 스키마 전체 (열·enum·ref·kind) | 아니오 |
| `GET /api/tables` | 표 이름과 행 수 | 아니오 |
| `GET /api/table/{이름}` | 행 배열. **기본값이라 빠진 열은 서버가 채워** 준다 | 아니오 |
| `PUT /api/table/{이름}` | 행 배열 통째 → 모든 표와 함께 검증 → 통과하면 `table.Format` → tmp→이름 바꾸기 | **예 (유일)** |
| `POST /api/validate` | CLI `validate` 와 같다 (V10 도 오류) | 아니오 |
| `GET /api/assetindex` · `GET /api/asset` | AssetTool 색인 요약 · 미리보기용 원본 파일 | 아니오 |

지킴이 : `127.0.0.1` 에만 붙음 · Host 머리 검사 · 토큰(`X-Datatool-Token`) · 본문 32MB 상한 · 쓰기 잠금(`sync.Mutex`).

### 1-2. 표 UI (Tabulator 6.5.3, `ui/app.js` 661줄)

| 기능 | 지금 |
| --- | --- |
| 편집 | 더블클릭으로 연다. 열 타입에 따라 input · number · tickCross(bool) · list(enum·ref·asset) |
| 정렬 | 머리 클릭. 저장 차례에는 영향 없음 (아래 2장 S3) |
| 검색·거르기 | **없음.** `headerFilter` 를 안 켰다 |
| 되돌리기 | Tabulator `history: true` (Ctrl+Z/Y) |
| 범위 선택·복사·붙이기 | `selectableRange` + `clipboardPasteAction: "range"` |
| 행 추가 | 맨 아래에 `<표>_<번호>` id 로 한 행 |
| 행 지우기 | **마지막으로 누른 한 행만.** 범위 선택한 여러 행은 못 지운다 |
| 검증 결과 | 오른쪽(좁으면 아래) 목록 + 틀린 칸 빨간 바탕. 목록을 누르면 그 칸으로 간다 |
| asset | image 는 32px 그림, audio 는 ▶, 주소 드롭다운(kind 로 거름), 색인 상태 띠 |
| 저장 | 버튼 또는 Ctrl+S. 결과는 토스트 3~6초 |
| 떠날 때 | 저장 안 한 변경이 있으면 표 옮기기·창 닫기에서 묻는다 |

### 1-3. 저장할 때 JSON 을 어떻게 다시 쓰나 (diff 에 바로 걸리는 자리)

UI 는 JSON 파일을 만들지 않고 행 배열만 보낸다. 서버는 받은 행을 데이터 파일 꼴로 이어 붙여 `table.Parse` 에 넣고,
검증을 통과하면 `fmt` 와 같은 `table.Format` 으로 쓴다.

| 무엇 | 어떻게 | diff 영향 |
| --- | --- | --- |
| 열 차례 | 늘 스키마 차례 | 없음 |
| 기본값 | 서버가 GET 때 채우고 PUT 때 같은 값이면 뺀다 | 없음 (파일이 이미 fmt 판이면) |
| 행 차례 | UI 가 `getData()` 차례(원래 읽은 차례)로 보낸다 | 정렬해도 없음 — 실측 |
| 문자열 | 다시 인코딩 (한글 그대로, HTML 이스케이프 끔) | fmt 판이면 없음 |
| **숫자** | 서버는 적힌 철자 그대로 둔다(`json.Number`). 그런데 **UI 가 JS Number 로 읽어 다시 쓴다** | `300.0`·`1.25e1`·`0.50` 꼴이 안 고친 줄에서 바뀜 — 실측 |
| 줄끝 · BOM | 늘 LF · BOM 없음 | 원본이 CRLF 로 커밋돼 있으면 첫 저장에 파일 통째 diff (fmt 도 같음) |
| 맨 끝 행 추가 | 앞 행 뒤에 쉼표가 붙는다 | 고친 줄 + 1줄 (JSON 꼴 때문, 피할 수 없음) |

**전제** : 파일이 한 번 `fmt` 를 거친 판이어야 「고친 줄만」이 성립한다. 손으로 쓴 파일은 첫 저장에서 fmt 와 같은 만큼 바뀐다.
이 저장소 `.gitattributes` 는 `*.json text eol=lf` 라 줄끝은 git 이 맞춰 준다. 게임 저장소에도 같은 줄이 있는지는 못 봤다.

## 2. U6 을 코드로 판정하는 길

### 2-1. 이 기계에 있는 것

| 수단 | 있나 |
| --- | --- |
| Node | v22.21.0 — **전역 `WebSocket` 있음** (CDP 클라이언트를 80줄로 짤 수 있다) |
| 크롬 | `C:/Program Files/Google/Chrome/Application/chrome.exe` 154 (Edge 154 도 있음) |
| Playwright (npm·python) | 없음. 브라우저 캐시 `ms-playwright` 도 없음 |
| python `websocket-client` | 없음 |
| Go 1.26.7 | 있음 (Go 로 CDP 를 짜려면 WebSocket 을 직접 구현하거나 라이브러리를 들여야 한다 — 바깥 라이브러리 0개 원칙과 부딪힘) |

### 2-2. 세 길 비교

| 길 | 보는 것 | 못 보는 것 | 비용 |
| --- | --- | --- | --- |
| **A. Node + 크롬 CDP (설치 없음)** ← 추천 | 사람과 같은 입력(더블클릭·타자·Enter·붙이기 이벤트·저장 버튼)부터 `git diff` 까지 전 구간. JS Number 왕복·편집기 커밋 시점 같은 UI 쪽 버그 | 실제 OS 클립보드(엑셀이 올리는 HTML·TSV 두 벌). 화면 갱신 체감 | 스크립트 3개 (scratchpad 에 시제품 있음) |
| B. PUT API 만 (Go 시험) | 서버 쪽 왕복 — 2,000행 받아 `Format` 했을 때 고친 줄만 바뀌나, 검증이 막나 | **UI 쪽 버그 전부.** 이번에 찾은 셋(붙이기·Ctrl+S·숫자 철자)이 하나도 안 잡힌다 | 시험 하나. 지금 시험에 2,000행 판이 없다 |
| C. Playwright 들이기 | A 와 같고 쓰기 편하다 | A 와 같음 | **새 패키지 설치 = 사용자 승인 사항.** A 로 충분해서 지금은 필요 없음 |

**추천 : A 를 정식 시험 도구로, B 를 Go 시험 하나로 같이 둔다.**
B 는 빠르고 CI 에서 돌고, A 는 사람이 할 U6 을 대신한다. A 는 Node 가 없는 기계에서 못 돌므로 Go 시험에 넣지 말고
`Testdata/` 밖 스크립트(예: `tools/u6/`)로 두는 것이 맞다 — 둘 자리와 이름은 설계 때 정한다.

### 2-3. 시제품 (scratchpad, 저장소 밖)

| 파일 | 하는 일 |
| --- | --- |
| `gen.js` | 스키마 `Testdata/table/ok` 에 맞춰 item 2,000 · monster 50 · drop 2,000 행을 만든다 (쉼표 든 list 원소·한글·소수 포함) |
| `cdp.js` | Node 내장 WebSocket 으로 쓰는 80줄 CDP 클라이언트 (탭 열기·eval·마우스·키·스크린샷·대화상자 자동 수락) |
| `u6.js` | 시나리오마다 `git checkout -- .` → 페이지 열기 → 사람처럼 고치기 → 저장 → `git diff --numstat` 으로 합격 판정 |

판정 꼴 : `git diff --numstat` 의 `더한줄 뺀줄 파일` 이 기대값과 같은가. 예) 세 칸 고침 → `item.json` 하나, `3 3`.
절차 : 데이터 폴더를 `git init` · 첫 커밋 → `core.autocrlf false`(줄끝 바뀜도 잡게) → `datatool serve --port N --json` 으로
주소를 받아 → 크롬 `--headless=new --remote-debugging-port=9333 --user-data-dir=<scratch>` → `node u6.js`.

## 3. 고치는 방향 (설계 판에서 정할 것, 여기선 후보만)

| 문제 | 후보 | 비고 |
| --- | --- | --- |
| P1·P2 붙이기 | Tabulator `clipboardPasteParser` 를 우리 함수로 바꿔 `\r\n`→`\n`, 끝 빈 줄 하나 버림 | 10줄 남짓. 「UI 는 값을 고쳐 주지 않는다」 원칙과 안 부딪힌다 — 값이 아니라 클립보드 꼴을 푸는 것 |
| S7 Ctrl+S | `save()` 첫 줄에서 열린 편집기를 확정(`document.activeElement.blur()` 등) | 저장 버튼 클릭은 이미 blur 가 일어나 괜찮다. 키보드 길만 문제 |
| F1 숫자 철자 | (가) `table.canonical` 이 숫자를 JS 와 같은 최단 꼴로 적게 해 `fmt` 와 UI 를 맞춘다, (나) UI 가 안 건드린 칸은 원래 글자를 들고 있다가 보낸다 | (가)가 「쓰기 규칙 한 곳」 원칙에 맞다. 대신 기존 파일에 `fmt` 를 한 번 돌리면 그런 줄이 한꺼번에 바뀐다 |
| D1 저장 실패 | `api()` 에서 fetch 예외를 잡아 빨간 토스트 | 5줄 |

## 4. 개선 후보

우선순위 : **상** = 데이터가 조용히 바뀌거나 저장을 잘못 믿게 함 · **중** = 자주 부딪힘 · **하** = 있으면 좋음.

| # | 후보 | 우선 | 크기 | 근거 |
| --- | --- | --- | --- | --- |
| 1 | 엑셀 붙이기 줄끝·끝 빈 줄 처리 | 상 | S | P1·P2 실측. 아래 행 값이 기본값으로 바뀌어도 검증이 못 잡는다 |
| 2 | 편집 중 Ctrl+S 가 입력을 확정하고 저장 | 상 | S | S7 실측 |
| 3 | 숫자 철자 정규화 (`fmt`·UI 일치) | 상 | M | F1 실측. 기존 데이터에 한 번 diff 가 생기는 판단이 같이 필요 |
| 4 | 저장 실패(서버 꺼짐·네트워크) 알림 | 상 | S | D1 실측. 지금은 눌러도 아무 일 없어 보인다 |
| 5 | 디스크 파일이 바뀌었으면 저장 전에 알림 (GET 때 해시·mtime → PUT 때 비교) | 중 | M | 코드 확인 — PUT 은 디스크 판을 안 견주고 통째로 덮는다. git pull·딴 편집기로 고친 것이 조용히 사라진다 |
| 6 | 머리 줄 검색·거르기 (`headerFilter`) | 중 | S | 2,000행에서 id 하나 찾을 길이 없다. 설계는 「Tabulator 몫」이라 했지만 켜지 않았다 |
